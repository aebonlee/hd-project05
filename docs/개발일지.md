# 개발일지 — 해외영업팀 통합 포털 + 딜러 미팅 대시보드 (hd-project05)

- 프로젝트: 해외영업팀 업무 자동화 — 클라이언트 미팅용 딜러 대시보드 + 팀 업무 통합 포털
- 기획: 최율아 (생성형 AI 업무자동화 전문가과정 1차수)
- 개발 기간: 2026-08-21
- 저장소: https://github.com/aebonlee/hd-project05

---

## 1. 요구사항 분석

14개 해외 딜러를 관리하는 해외영업팀의 두 가지 요구를 하나의 반응형 웹앱으로 통합했다.

1. **팀 업무 통합 포털 (6개 기능)** — 기획자가 제안한 우선순위 3단계를 그대로 따름
   - 1단계: 주간업무 작성·자동 알림(B-1), 경과채권 바로가기(B-2)
   - 2단계: 출장 일정 캘린더(B-5), 팀회의 일정(B-6), 환율 입력(B-4)
   - 3단계: 지역별 매출 추이 그래프(B-3)
2. **클라이언트 미팅용 딜러 대시보드** — 엑셀 업로드 → 14개 딜러별 전환 조회, 12개월 히스토리, 오프라인(비행기) 사용 대응

잦은 해외 출장 특성상 **모바일 조회 필수**를 기본 전제로 했다.

## 2. 설계 결정

| 결정 | 이유 |
|---|---|
| 단일 페이지 웹앱 + 7개 뷰 네비게이션 | "한 화면에서 6개 기능 접근" 요구. 빌드 없이 GitHub Pages 배포 |
| 모바일 우선 반응형 (390px 기준, 900px+ 사이드바) | 출장 중 모바일 접속 빈도 높음 (기획서 가정) |
| `js/store.js` 어댑터 패턴 (localStorage 기본) | 사내 보안 정책 미확정 → 구글 스프레드시트/Supabase로 저장 계층만 교체 가능하게 분리. GoogleSheetsAdapter 골격 동봉 |
| 알림 발송은 수신자 목록(화면 편집) + 발송 로그 + mailto 초안 | 개인 환경에 메일 서버 없음. Apps Script MailApp 연동법 README 명시 |
| 월간 캘린더 직접 구현 (외부 라이브러리 미사용) | 의존성 최소화, 출장/회의 병기·팀원별 색상 등 요구에 맞춤 |
| Chart.js·SheetJS **로컬 동봉** (CDN 미사용) | 오프라인 사용 요구 + 개발 환경 CDN 차단 대응 |
| 오프라인 내보내기 = self-contained 단일 HTML | 비행기·인터넷 미연결 지역에서 딜러 자료 열람 (라이브러리 인라인 임베드) |

## 3. 구현 내역

1. **B-1 주간업무**: ISO 주차 자동 계산 폼, 주차·작성자 필터 목록, 사용자 선택 로그인(팀원 6명 — 팀원은 본인 작성분만, 책임자는 전체 수정), 알림 발송(수신자 편집 + 로그 + mailto 초안).
2. **B-2 경과채권 바로가기**: 링크 목록 관리(법인/딜러·파일명·경로·갱신일), URL 새 탭 열기 / UNC 경로 클립보드 복사.
3. **B-4 환율**: 기준월×통화 입력(숫자·양수 검증), 입력자·입력일 자동 기록, 당월 고시 표 + 최근 12개월 매트릭스.
4. **B-5/B-6 출장·회의 캘린더**: 순수 JS 월간 캘린더(팀원별 색상 bar, 회의는 점선 병기), 목록 뷰 CRUD, 다가오는/지난 회의 구분.
5. **B-3 지역별 매출 추이**: 주간업무 매출 자동 집계 → 주간/월간·라인/막대 전환 차트, 지역 칩 필터, 합계 표.
6. **딜러 대시보드**: 14개 딜러 전환, KPI 카드(매출·재고·채권·경과채권 경고색·계약조건), 12개월 히스토리 차트, 엑셀 업로드(행 검증·중복 덮어쓰기·신규 딜러 자동 등록), 오프라인용 HTML 내보내기.
7. **샘플 데이터**: `make_samples.py` — 딜러 14개(가상명)·12개월 실적·주간업무 8주치·출장 6건·회의 4건·환율 12개월·경과채권 링크 6건 + 딜러실적 엑셀 양식/샘플(작성안내 시트 포함).
