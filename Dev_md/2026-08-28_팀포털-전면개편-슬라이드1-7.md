## 막혀서 대체 구현한 것 (대표님이 최율아님께 설명 필요)

1. **efam 실시간 연동 불가** — 사내망 전용이라 웹에서 직접 못 연다. 엑셀 업로드로 대체.
2. **팀즈 공유 폴더 URL** — 받은 자료에 실제 링크가 없어 빈 입력창만 만들었다. 실제 URL을 받으면 `#priceTeamsLink`에 입력→저장하면 바로 동작한다.
3. **매주 월 14시 자동 발송** — 정적 사이트라 예약 실행이 안 된다. "다음 발송 시각 표시 + 원클릭 발송"으로 근사했다.
4. **AI 회의 요약** — 음성→텍스트 전사까지만(브라우저 내장, 무료). 실제 AI 요약(LLM 호출)은 API 키가 필요해 2단계로 미뤘다.
5. **회사 CI 색상/로고** — hd-ce.com/kr에서 헥스코드를 못 뽑았다(WebFetch로 시도했으나 페이지에 노출된 CSS 변수가 없음). **브랜드 컬러를 바꾸지 않고 기존 navy 톤(parts-sales-dashboard.html과 동일 계열)을 유지했다.** 정확한 컬러 가이드나 로고 파일을 받으면 `css/style.css`의 `--navy`/`--navy-dark` 두 토큰만 바꾸면 전체가 바뀐다.

## 데이터 모델 변경
- 신규 컬렉션: `receivableRows`, `sapSales`, `priceItems`, `teamsLinks` — `store.js`의 `COLLECTIONS`에 추가(백업 내보내기/가져오기·팀 공용 문서 동기화 대상에 포함).
- `store.js` `validateBackup()`을 **관대하게 수정** — 새로 추가된 컬렉션이 없는 구버전 백업 파일도 가져오기 가능(누락분은 빈 배열로 채움). 원래는 COLLECTIONS 전부가 배열로 존재해야만 통과였는데, 그러면 이번에 추가한 4개 컬렉션 때문에 **어제 이전에 내보낸 백업 파일이 전부 가져오기 실패**하는 회귀가 생길 뻔했다. 실제로 고쳤는지는 `test/logic.test.js`의 "exportAll → importAll 왕복" 테스트로 확인.
- `weeklyReports`/`exchangeRates`/`meetings`는 필드만 추가(`category`, `notes`)했고 기존 필드는 안 건드림 — 과거 데이터도 그대로 읽힌다.

## 검증
- `node test/logic.test.js` — 33개 전부 통과(기존 30 + 신규 SAP 로직 3개 추가)
- `node --check` 전체 js 통과
- index.html의 모든 JS `$('#id')` 참조가 실제 DOM에 존재하는지, id 중복이 없는지 스크립트로 대조 — 이상 없음
- **브라우저 실제 렌더링(Playwright)은 이번엔 못 돌렸다** — 로컬에 playwright 미설치, 네트워크 설치는 시도 안 함(백그라운드 작업이라 오래 걸리는 설치를 새로 시작하지 않음). CI(`test.yml`)가 push 후 자동으로 `tests/smoke.browser.js`를 돌리니 거기서 최종 확인된다. **CI 결과를 대표님이 확인해 줄 것.**
